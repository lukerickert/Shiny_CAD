SHINYCAD - installation and start
=================================

Full manual: docs\ (contents in README.md; installation docs\01-installation.md, Explicit tab docs\13-explicit.md).

Requirements
------------
- Windows 10 or 11, 64-bit.
- Python 3.10 to 3.14, 64-bit, from python.org, with the py launcher.
  "py -0" in a command window lists the installed versions.
- Internet connection for the first start (approximately 500 MB of packages).

Solvers (not installed by start.bat; docs\01-installation.md section 1.1)
-------------------------------------------------------
Unpacked in the folder solvers\ of the program, the solvers are found without settings.
- CalculiX ccx (Analysis tab): PrePoMax, https://prepomax.fs.um.si/downloads/
  Unpack "PrePoMax v<version>.zip" to solvers\ (its Solver folder holds ccx).
  A PrePoMax folder in the user folder, Desktop, Downloads, Documents, Program Files
  or C:\ is also found.
- Explicit tab, Windows (local runs): the last official OpenRadioss Windows release,
  archived by OpenCourant:
  https://github.com/OpenCourant/extlib/releases/tag/upstream-latest-20260728-win64
  1. Download OpenRadioss_win64.zip from that page.
  2. Check the file in PowerShell:
       Get-FileHash .\OpenRadioss_win64.zip -Algorithm SHA256
     The hash given on the page is
       04dfecb0bf26ce071132cda86dc6861417c6a4127a389befe82b8c97341b3268
  3. Unpack it to solvers\OpenRadioss\ (starter_win64.exe in exec\ or one folder deeper).
  4. Check that exec\ also holds anim_to_vtk_win64.exe and th_to_csv_win64.exe.
  Siemens discontinued OpenRadioss on 2026-10-01 and deleted its GitHub releases.
  OpenCourant (https://github.com/OpenCourant) is its community continuation, with the
  same executable names. Its release of 2026-10-05 has no Windows package. When one is
  published at https://github.com/OpenCourant/OpenCourant/releases, unpack it to
  solvers\OpenCourant\ and delete solvers\OpenRadioss\.
- Explicit tab, Linux server (remote runs): OpenCourant_linux64.zip from
  https://github.com/OpenCourant/OpenCourant/releases; Exec dir = its exec folder.
Other programs:
- ParaView (Explicit tab: strain extraction, renders).
- OpenSSH of Windows and a Linux server with OpenCourant and task-spooler (remote runs).

Installation
------------
1. Right-click the zip file > Extract All..., to a folder with a short path, for example C:\.
   Keep all files and folders together. start.bat does not run from inside the zip file.
2. Double-click start.bat.
   The first start creates the Python environment in %LOCALAPPDATA%\drawgen\venv
   and installs build123d, flask, ezdxf, reportlab and gmsh from requirements.txt.
3. The browser opens http://localhost:8765.
   Close the command window to stop the server.

Later starts use the existing environment.
When requirements.txt changes, start.bat installs the packages again.

Troubleshooting
---------------
start.bat keeps its window open with a message when it stops.
- "Windows protected your PC": the zip came from the internet. Click More info > Run anyway,
  or before extracting: right-click the zip > Properties > Unblock.
- "run.py, requirements.txt or drawgen\web.py is missing": start.bat was started from inside
  the zip. Extract the zip and start start.bat in the extracted SHINYCAD folder.
- "Python 3.10 to 3.14 was not found": install Python 3.14 (64-bit) from python.org with the
  options "py launcher" and "Add python.exe to PATH".
- "Package installation failed": no connection to pypi.org (internet, proxy, firewall).
- "SHINYCAD stopped with an error": the lines above the message give the cause.

First use
---------
1. Project tab: set the Projects folder, then New... to create a project.
2. Drawings tab: Title block... (toolbar) opens the title block editor
   (title block layout, logo, line widths, text heights; Save title block writes config.json).
3. Analysis tab, Settings: the line below Solver (ccx) gives the CalculiX executable in use.
4. Explicit tab, Solve panel: the line below the fields gives the OpenCourant executables
   found. Settings of this PC are written to config.local.json > explicit.
   Without that entry the ORC3 configuration %APPDATA%\ORC3\workspace_config.json is read.

Command line options (run.py, through the environment):
  run.py --port 9000        other port
  run.py --no-browser       no browser at the start
  run.py --browser "<cmd>"  browser command for this start

Tests
-----
run_tests.bat runs the automatic tests in tests\ (first run installs pytest, pyflakes and
Playwright with Chromium, approximately 150 MB).
  run_tests.bat         all tests
  run_tests.bat fast    without the browser tests

Package contents
----------------
start.bat, run.py          start of the program
requirements.txt           Python packages
config.json                settings and title block
config.local.json          settings of this PC (projects folder, open project, Explicit settings,
                           browser, CalculiX path); created at the first change, not in the package
publish.bat                commit and push of the program folder to GitHub (docs\02-files.md section 2.2)
logo.png                   logo of the title block
README.md                  overview and contents of the manual
docs\                      manual, one page per section
SHINYCAD_functions.png     overview of the functions
drawgen\                   program (server, drawing, part, assembly, analysis modules)
drawgen\static\            interface (HTML, JavaScript, three.js 0.160.0, MIT licence)
solvers\                   solver packages (PrePoMax, OpenCourant); solvers\README.txt
drawgen\explicit\          Explicit tab: ORC3 core, inp2rad.py and inp2rad_run.py
                           (inp2rad: Altair Engineering, MIT licence), deck generator
                           (deck.py, deck_mesh.py, deck_stepgen.py)
tests\                     automatic tests, run_tests.bat
parts\, sketches\, assemblies\, annotations\
                           document folders used when no project is open (empty)
