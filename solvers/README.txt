Solver packages for SHINYCAD (README.md section 1.1).

CalculiX: unpack PrePoMax (https://prepomax.fs.um.si/downloads/) here,
  so that its Solver folder is solvers\PrePoMax v<version>\Solver\.
Explicit tab (Windows): unpack OpenRadioss_win64.zip, the last official OpenRadioss
  Windows release archived by OpenCourant
  (https://github.com/OpenCourant/extlib/releases/tag/upstream-latest-20260728-win64),
  to solvers\OpenRadioss\, so that starter_win64.exe is in solvers\OpenRadioss\exec\
  or one folder deeper.
  When OpenCourant publishes a Windows package
  (https://github.com/OpenCourant/OpenCourant/releases), unpack it to
  solvers\OpenCourant\ and delete solvers\OpenRadioss\.

The program finds both without settings.
